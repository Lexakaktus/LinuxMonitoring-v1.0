# Linux Monitoring v1.0
Linux Monitoring v1.0 — это набор Bash-скриптов для анализа и мониторинга системы Linux.
Проект позволяет:
- получать подробную информацию о системе;
- выводить данные в удобном и настраиваемом цветном формате;
- сохранять результаты в файл;
- анализировать файловую систему и находить самые большие файлы и директории.

Проект реализован полностью на Bash и предназначен для запуска в Linux-среде (рекомендуется Ubuntu Server 20.04+).

## Структура проекта

Все скрипты находятся в директории src/ и разбиты по заданиям:
Все скрипты находятся в директории `src/` и разбиты по заданиям:

```text
src/
├── 01/
│   └── main.sh
├── 02/
│   └── main.sh
├── 03/
│   └── main.sh
├── 04/
│   └── main.sh
└── 05/
    └── main.sh
```

Каждая папка соответствует отдельной задаче проекта.
Основной файл для запуска — main.sh.

Все скрипты:
- проверяют корректность входных параметров;
- корректно завершаются при ошибках;
- разделены на логические модули.

## Установка и запуск

1. Клонировать репозиторий
2. Перейти в нужную папку:
   ```cd src/0X``` 
4. Дать права на выполнение:
   ```chmod +x main.sh```
6. Запустить скрипт:
   ```./main.sh ...``` параметры отличаются у каждого скрипта, полное описание ниже

## Функциональность
### Part 1 — Вывод параметра 
Скрипт принимает один аргумент:
- если аргумент — строка → выводит её;
- если аргумент — число → сообщает об ошибке.

[тут будет картинка позже)]

### Part 2 — Информация о системе

Скрипт выводит:

- HOSTNAME
- TIMEZONE
- USER
- OS
- DATE
- UPTIME / UPTIME_SEC
- IP, MASK, GATEWAY
- RAM_TOTAL, RAM_USED, RAM_FREE
- SPACE_ROOT, SPACE_ROOT_USED, SPACE_ROOT_FREE

После вывода предлагает сохранить результат в файл формата ``` DD_MM_YY_HH_MM_SS.status```

Пример запуска:
``` ./main.sh ```


### Part 3 — Цветной вывод (через параметры)

Скрипт принимает 4 числовых параметра (от 1 до 6): <span style="color: white;"> 1 - белый </span>, <span style="color: red;"> 2 - красный </span> , <span style="color: green;"> 3 - зелёный </span> , <span style="color: blue;"> 4 - синий </span> , <span style="color: purple;"> 5 - фиолетовый </span> , <span style="color: black;"> 6 - чёрный </span>

Параметры:
1. фон названий
2. цвет названий
3. фон значений
4. цвет значений

Пример запуска:
```./main.sh 1 2 3 4  ```

Если цвета названий/значений и фона совпадают — скрипт выводит сообщение об ошибке и завершает работу.


### Part 4 — Цвета через конфигурационный файл

Скрипт запускается без параметров.
Цвета берутся из конфигурационного файла:
``` src/04/config.conf ```

Если параметр не указан — используется схема по умолчанию.

После вывода информации дополнительно показывается текущая цветовая схема.

Пример запуска:
```./main.sh  ```

### Part 5 — Анализ файловой системы

Скрипт принимает путь к директории (обязательно с / в конце):

``` ./main.sh mydir/ ```

Выводит:

- общее количество папок;
- ТОП-5 самых больших папок;
- общее количество файлов;
- количество:
  * .conf
  * текстовых файлов
  * исполняемых
  * .log
  * архивов

- ТОП-10 самых больших файлов (путь, размер, тип);
- ТОП-10 самых больших исполняемых файлов (путь, размер, MD5);
- время выполнения скрипта.
